Picture Model Training Kit

The easy way
Download Picture-Model-Training.exe from the same page as this kit and press Enter on it: a wizard asks for the
folder and how much to train, prepares the computer, installs everything and trains, saying each step through
your screen reader. The rest of this file explains the same steps done with the .cmd files.

What it does
This kit teaches the Digital Accessibility Toolkit's picture model (the uncensored Qwen3-VL) to describe pictures
the way a blind reader needs. It learns from about 44,000 pictures that people have described, from these
collections:
- DOCCI: photos, each described carefully in about 120 words.
- VizWiz: photos taken by blind people, with one-sentence descriptions, and the questions blind people asked about
  their own photos with the answers ("I can't tell from this picture" when people could not answer).
- TextCaps and TextVQA: pictures with text in them (signs, labels, screens), described and asked about, so it learns
  to read text out.
- Localized Narratives: everyday photos that people described aloud.
- Cooper Hewitt, Smithsonian Design Museum, and the Art Institute of Chicago: descriptions their staff wrote for
  blind visitors and screen-reader users.
- The Metropolitan Museum of Art: its best-known works, learned by name ("What artwork is this?").
- Europeana: objects from museums and archives across Europe, learned as "Tell me about this museum object".
- NASA: space, Earth and aviation pictures with NASA's captions.
- COCO and Crossmodal-3600: everyday photos from around the world, each described in one sentence (only photos whose
  own licence allows it).
- Canterbury Museum and Auckland Museum (New Zealand): their staff's descriptions of how objects and old photographs
  look.
- Wellcome Collection (UK): prints, drawings and photographs, learned by their descriptive titles.
- Ready-made packs, built on GitHub and downloaded from the kit's own repository: the Smithsonian museums'
  accessibility descriptions and gallery labels, questions about everyday photos answered with the reason why,
  Wikimedia Commons' best pictures with their captions, and Te Papa (Museum of New Zealand) records.
- Wikipedia (only with "Start Training with Wikipedia"): pictures with the alt text Wikipedia's writers wrote for
  screen-reader users, from two collections (WIT and Concadia).
It trains a small add-on to the model, then tests whether the model really got better. The model itself is not
changed. Nothing is sent anywhere; the kit only downloads what it needs. If one collection's website is down, the
kit says so and carries on with the others.

What you need
- An NVIDIA graphics card with at least 12 GB of memory for the 4B model, or 16 GB for the 8B model, with an
  up-to-date NVIDIA driver.
- About 90 GB of free disk space (110 GB for the 8B model) on the drive where you unpack the kit.
- An internet connection for the downloads, about 40 GB in all (more with Wikipedia).
- Time: the downloads take a few hours, and training on all the pictures takes roughly a day on a fast card.
  "Quick Try" uses a tenth of the pictures and takes an hour or two.

How to start
1. Unpack this zip to a folder on a drive with enough free space, for example D:\Training. Do not run it from
   inside the zip.
2. Press Enter on "Prepare This Computer.cmd" once and answer Yes when Windows asks for administrator permission.
   It stops sleep and hibernation, pauses Windows Update for 7 days, allows long file names and asks Windows
   Defender not to scan the kit folder. "Restore Normal Settings.cmd" puts it all back after the training.
3. Start with "Quick Try.cmd" (press Enter on it) to check that everything works on your computer. Then press Enter
   on "Start Training.cmd" for the real training of the 4B model. Pictures already downloaded by the quick try are
   used again.
   Other choices:
   - "Start Training Full.cmd": up to three times as many pictures from every collection (about 110,000), for the
     best result if the computer can run for several days (roughly three days on a fast card).
   - "Start Training 8B.cmd": the 8B model (only with a 16 GB card or bigger; do the 4B model first).
   - "Start Training with Wikipedia.cmd": also learns from Wikipedia. Wikipedia's text is under the CC BY-SA 4.0
     licence, so this add-on must be shared under CC BY-SA 4.0 too. It is published as a separate choice; the
     normal add-on stays under a permissive licence.
4. A console window opens. It says each step in plain words; JAWS and NVDA read it. Every line also goes into the
   file training-log.txt in the kit folder, which you can open at any time.
5. Leave the computer on. The kit stops Windows from going to sleep while it runs; the screen may turn off.

The steps it says
1. Checking the graphics card and the disk.
2. Downloading the model (about 9 GB for 4B).
3. Downloading the pictures of each collection and making them smaller. It says each collection's name and how
   many pictures are ready.
4. Testing the model before training (about half an hour).
5. Training: the long part. It says how many pictures are done and how long is left every 200 pictures.
6. Testing the trained model on the same pictures.
7. Writing the report and the file to send.

If it stops
You can close the window at any time, or the computer can restart. Press Enter on the same Start file again: it
carries on where it stopped. Training carries on from its last save; a collection already downloaded is not
downloaded again. If it says STOPPED, it gives the reason on the same line, for example a card with too little
memory or too little disk space.

When it has finished
It says FINISHED and whether the model got better. Two files matter:
- The report (for example report-4b.txt) in the kit folder: the scores before and after for each collection, and
  examples, each with the question, a person's answer, and the model's answer before and after training.
- The zip in the "result" folder (a few hundred MB): this is what to send. Tell Claude the training has finished
  and you will be told how to send it. The add-on is only published in the toolkit if the tests show it is better.

Afterwards
You can delete the "work" folder to get the disk space back (keep the "result" folder until the file is sent).
